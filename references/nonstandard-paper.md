# Nonstandard-paper reading guide

Use this guide when a document does not cleanly fit the empirical/review routes, including theory papers, qualitative or mixed-methods studies, protocols/registered reports, theses, dissertations, conference abstracts, and incomplete manuscripts.

## First response

State the detected genre and which usual elements are absent, merged, or unavailable. Explain that an IMRaD-shaped analysis would be misleading when appropriate.

## Adaptation principles

- **Theory paper:** map concepts, propositions, mechanisms, supporting examples, boundaries, and testable implications.
- **Qualitative study:** identify research question, epistemic/methodological framing if reported, sample/context, data generation, analytic approach, themes, illustrative evidence, and reflexive limitations. Do not use quantitative-validity language as a substitute for qualitative appraisal.
- **Mixed-methods study:** state what each component contributes and whether/how the paper integrates them.
- **Protocol / registered report:** distinguish planned procedures and hypotheses from observed results; do not describe plans as findings.
- **Thesis / dissertation:** state that chapter structure and contribution may differ from a journal article; analyze the relevant chapter(s) without assuming a single-study design.
- **Abstract collection / incomplete manuscript:** restrict output to visible text and clearly state that methods, results, references, or figures may be unavailable.

## Module handling

Retain the same four Chunk names and evidence rules. Replace absent components with an explicit `Not reported / Not readable` note, not speculation. The language and citation modules apply only to text and reference data actually present.
